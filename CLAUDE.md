## Project Overview

Remarkable is a desktop application for synchronizing data between a computer and a reMarkable tablet. It provides data backup and document visualization capabilities.

## Git Workflow

- Always create a new branch for changes before committing. Never commit directly to `main`.
- Use descriptive branch names (e.g., `feature/sync-engine`, `fix/connection-timeout`).
- Push branches and create pull requests for merging into `main`.
